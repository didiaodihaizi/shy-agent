## ADDED Requirements

### Requirement: 空状态与聊天状态区分布局
系统 MUST 在无用户消息的空状态与已有对话的聊天状态使用不同的 composer 控件排布。空状态 MUST 将工作空间选择置于输入框外底栏区域；聊天状态 MUST NOT 在底栏展示工作空间选择（未绑定时可在框内或既有策略处选择，但 MUST 符合图二紧凑结构：框内含权限控件）。

#### Scenario: 空状态展示外置工作空间
- **WHEN** 当前会话尚无用户消息（空状态）
- **THEN** 输入区呈现居中大 composer，且「选择工作空间 / 项目」控件出现在输入框外的底栏区域

#### Scenario: 聊天状态紧凑底栏
- **WHEN** 会话已有用户消息（聊天状态）
- **THEN** composer dock 于对话下方，框内左侧含添加与默认权限入口，右侧含固定宽模型选择与发送或停止控件

### Requirement: 模型选择固定宽度
系统 MUST 使会话模型选择控件在空状态与聊天状态均使用固定宽度；过长模型名 MUST 以省略方式显示，不得撑开整体底栏布局。

#### Scenario: 长模型名不撑破布局
- **WHEN** 当前模型显示名长于固定宽度
- **THEN** 选择框宽度保持不变，文本截断或省略，相邻控件位置稳定
